Disciplina: Fundamentos de Programação

1. Criação e Contexto Histórico

  • Criador: Guido van Rossum.
  • Ano: Início nos anos 80, lançada oficialmente em 1991.
  • Contexto: Criada na Holanda (CWI) para ser uma linguagem simples, legível e capaz de substituir scripts complexos de Shell e C. O nome vem do grupo de comédia Monty Python.

2. Características e Paradigmas

O Python é conhecido por sua filosofia de código limpo e legível.

  • Multiparadigma: Suporta Orientação a Objetos, Imperativa e Funcional.
  • Interpretada: O código é executado linha a linha, sem compilação prévia.
  • Tipagem Dinâmica: Não exige declaração de tipos de variáveis.

3. Onde é utilizada?

  • Ciência de Dados e Inteligência Artificial (Google, NASA).
  • Desenvolvimento Web Back-end (Instagram, Pinterest).
  • Automação de tarefas e Scripts.

4. Sintaxe Básica: "Olá, Mundo"

Abaixo, um exemplo de como imprimir texto na tela em Python:

# Código em Python
print("Olá, Mundo")

Explicação: A função print() exibe o conteúdo entre parênteses na saída padrão.

5. Vantagens e Desvantagens

Vantagens Desvantagens
Legibilidade: Sintaxe muito próxima do inglês, facilitando o aprendizado. Velocidade: Por ser interpretada, é mais lenta que linguagens como C ou Java em processamento pesado.
Bibliotecas: Possui um ecossistema vasto para quase qualquer necessidade. Memória: Consome mais memória RAM devido às suas estruturas de dados dinâmicas.
